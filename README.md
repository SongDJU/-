# 총무관리 시스템

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

총무 업무를 효율적으로 관리할 수 있는 웹 기반 관리 시스템입니다.

## 📋 주요 기능

### 1. 대시보드 📈
- 총 예산, 지출, 잔액을 한눈에 확인
- 회원 수 통계
- 최근 활동 내역 표시
- 실시간 재정 상태 모니터링

### 2. 예산 관리 💰
- 예산 항목 추가 및 삭제
- 항목별 예산 설정
- 예산 사용 내역 추적

### 3. 지출 관리 💳
- 지출 내역 등록
- 날짜별, 항목별 지출 분류
- 사용처 및 상세 내용 기록
- 지출 내역 조회 및 삭제

### 4. 회원 관리 👥
- 회원 정보 등록
- 역할 구분 (일반 회원, 관리자, 총무)
- 회원 목록 조회 및 관리

### 5. 보고서 📄
- 기간별 재정 보고서 (월별, 분기별, 연도별)
- 항목별 지출 분석
- 예산 사용률 시각화
- 예산 대비 지출 현황

### 6. 데이터 관리
- 로컬 스토리지를 통한 데이터 저장
- JSON 형식으로 데이터 내보내기
- 브라우저 기반 데이터 관리

## 🚀 시작하기

### 필요 사항
- 웹 브라우저 (Chrome, Firefox, Safari, Edge 등)
- 로컬 서버 (선택사항)

### 설치 방법

1. **파일 다운로드**
   ```bash
   git clone <repository-url>
   cd webapp
   ```

2. **브라우저에서 실행**
   - `index.html` 파일을 더블 클릭하여 브라우저에서 열기
   
   또는
   
   - 로컬 서버 실행 (Python 사용 시):
   ```bash
   python -m http.server 8000
   ```
   그 후 브라우저에서 `http://localhost:8000` 접속

3. **Node.js 서버 사용 시**:
   ```bash
   npx serve
   ```

## 📖 사용 방법

### 1. 예산 설정
1. 상단 메뉴에서 "예산 관리" 클릭
2. 항목명, 예산액, 설명 입력
3. "예산 추가" 버튼 클릭

### 2. 지출 기록
1. "지출 관리" 탭 선택
2. 지출 항목 선택 (미리 등록된 예산 항목)
3. 지출액, 날짜, 사용처, 설명 입력
4. "지출 추가" 버튼 클릭

### 3. 회원 등록
1. "회원 관리" 탭 선택
2. 이름, 이메일, 전화번호, 역할 입력
3. "회원 추가" 버튼 클릭

### 4. 보고서 확인
1. "보고서" 탭 선택
2. 기간 선택 (이번 달, 분기, 올해, 전체)
3. 항목별 지출 및 예산 사용률 확인

### 5. 데이터 백업
1. 우측 상단 "데이터 내보내기" 버튼 클릭
2. JSON 파일이 다운로드됨

## 🛠 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**: 반응형 디자인, Flexbox, Grid
- **JavaScript (ES6+)**: 순수 JavaScript, LocalStorage API
- **아이콘**: 이모지 사용

## 📱 반응형 디자인

- 데스크톱 (1200px 이상)
- 태블릿 (768px - 1199px)
- 모바일 (767px 이하)

모든 디바이스에서 최적화된 사용자 경험을 제공합니다.

## 🎯 주요 특징

✅ **간편한 사용**: 복잡한 설치 없이 즉시 사용 가능  
✅ **직관적인 UI**: 깔끔하고 이해하기 쉬운 인터페이스  
✅ **실시간 업데이트**: 데이터 입력 시 즉시 반영  
✅ **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원  
✅ **데이터 백업**: JSON 파일로 쉽게 내보내기  
✅ **무료 사용**: 별도의 서버나 구독료 없음  

## ⚠️ 주의사항

- 브라우저의 로컬 스토리지를 사용하므로 캐시를 지우면 데이터가 삭제됩니다.
- 중요한 데이터는 정기적으로 내보내기 기능을 사용하여 백업하세요.
- 여러 브라우저 또는 기기에서 사용 시 데이터가 동기화되지 않습니다.
- 민감한 재정 정보를 다루므로 공용 컴퓨터 사용 시 주의하세요.
